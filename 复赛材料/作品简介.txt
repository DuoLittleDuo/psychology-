「同频」是一款面向穿戴设备的 AI 心理陪伴系统，方向为 Agent 创新。

现有 AI 心理产品多用"有问必答"的响应式范式：开口才回应，情绪一波动就推送。但心理支持恰恰相反——深夜一条不合时宜的问候，可能比沉默更让人疲惫。痛点不是陪伴不够，而是时机与强度失控。
「同频」把"该不该出现"前置为独立决策层。系统由五个 Agent 经 MessageBus 异步总线协同构成：感知 Agent 经健康、环境、行为、对话四通道采集信号并构建状态快照；记忆 Agent 以瞬时、短期、长期三层记忆区分"临时波动"与"长期性格"；决策 Agent 以情绪×社交意愿九宫格完成秒级判定，需持续介入时生成多步渐进任务链；安全 Agent 独立常驻，以四级危机响应兜底；执行 Agent 负责卡片生成与跨端分发。默认动作是不介入，而非推送。

技术上，核心引擎以 TypeScript 实现，共 51 个源文件、约 12,800 行。感知四通道对接鸿蒙 Health Kit、位置与日历 API、UsageStats 及端侧 NLU，数据不出设备；分布式能力已完成接口层设计，ArkTS 迁移为下一阶段工作。
