## 视觉设计说明

### 配色体系

主色取自中国传统色，全文低饱和、高明度，契合心理陪伴场景需要的克制感。

| 用途 | 颜色 | 色值 |
|---|---|---|
| 九宫格渐变 | 玫瑰粉 ↔ 月白 | `#F4C2CA` ↔ `#D6ECF0` |
| 面板渐变 | 岫烟青 → 霜纨白 | `#4DCDD8` → `#FCF9E8` |
| 主标题渐变 | 深藏青 → 青 → 橙 | `#0f172a` → `#0891b2` → `#d97706` |

面板渐变叠有极淡颗粒噪点（SVG `feTurbulence`，不透明度 0.05），增加质感而不干扰阅读。

### 交互逻辑

核心交互原则是**先判断"该不该出现"，再决定"如何出现"**：

```
状态输入 → L1 九宫格判定是否介入 → [不介入] 结束
                                 → [介入]   L2 生成渐进任务链
                                            → 记忆召回补充背景
                                            → 安全层审查
                                            → 多端分发执行
```

- **九宫格**：情绪 × 社交意愿两轴，9 个象限各自对应不同介入策略，
  包括"不打扰"——这是与常规陪伴产品最大的设计差异。
- **当前象限面板**：实时显示所处象限、主行动与三项状态，随状态变化触发形变动效。
- **协作记录**：展示 Agent 之间的接力过程，强调系统决策可解释。

### 排版与动效

- 中文标题使用合成斜体（`font-style: italic`），并预留 `padding` 避免字形被裁切。
- 面板入场使用 GSAP 时间线错峰淡入；象限切换使用 `back-to-out` 缓动。
- 所有动画均遵循 `prefers-reduced-motion` 降级。
